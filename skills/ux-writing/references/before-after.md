# Before and after

Rewrites by pattern. Each shows the original, the rewrite, and the rule that drove it.
Copy the shape of the "After" column when writing new strings.

## Buttons

| Before | After | Rule |
| --- | --- | --- |
| Submit | Create account | Verb + noun; say what happens |
| OK | Save changes | Name the action, not the acknowledgment |
| Yes / No (on "Delete this file?") | Delete file / Cancel | Button repeats the verb in the question |
| Click Here To Learn More | View pricing plans | Link says where it goes; sentence case |
| Continue | Continue to payment | Add the destination when the next step is not obvious |
| Proceed | Place order | Plain verb; name the commitment |
| Loading... | Saving draft… | Loading text continues the verb |

## Errors

| Before | After | Rule |
| --- | --- | --- |
| Oops! Something went wrong. | We couldn't save your changes. Check your connection and try again. | What happened, how to fix; no "oops" |
| Invalid input | Enter a date in the format DD/MM/YYYY | State the rule |
| Error 403 | You don't have access to this project. Ask an admin to invite you. (Error 403) | Plain cause and action; code as secondary |
| You entered an invalid email address | Email address needs an @ and a domain, like name@example.com | Do not blame; give an example |
| Password is invalid | Password needs at least 12 characters | State the specific unmet rule |
| Payment failed | Your card was declined. Try another card or contact your bank. | Cause if known; next action |
| Upload error | "report.pdf" is 32 MB. Files can be up to 25 MB. | Name the object and the limit |
| Session expired | You've been signed out after 30 minutes of inactivity. Sign in again to continue; your draft is saved. | Why, action, and reassurance about data |

## Empty states

| Before | After | Rule |
| --- | --- | --- |
| No data | **No invoices yet** · Invoices appear here after your first sale. · [Create invoice] | What goes here, why empty, one action |
| No results found. | **No results for "acme"** · Check the spelling or clear filters. · [Clear filters] | Echo the query; offer recovery |
| Nothing here! | **You're all caught up** · New mentions will appear here. | Cleared state reads as success, not absence |
| This list is empty. Start adding items to populate this list. | **No team members yet** · Invite people to collaborate on projects. · [Invite people] | Specific object; benefit; action |

## Confirmations

| Before | After | Rule |
| --- | --- | --- |
| Are you sure? [OK] [Cancel] | **Delete "Q3 roadmap"?** · This deletes the project and its 14 files for everyone. You can't undo this. · [Delete project] [Cancel] | Name object and consequence; verb on button |
| Are you sure you want to archive? | (no dialog) Toast: "Project archived. [Undo]" | Reversible actions use undo, not confirmation |
| Warning! This action is permanent! | **Remove Jordan from Acme?** · They'll lose access to all projects immediately. · [Remove member] | Consequence in plain terms; no alarm words |

## Success and status

| Before | After | Rule |
| --- | --- | --- |
| Success! | Invite sent to jordan@acme.com | Say what happened, to what |
| Your changes have been saved successfully. | Changes saved | Past tense, short, no "successfully" |
| Item has been deleted. | Message deleted. [Undo] | Offer undo where possible |

## Forms

| Before | After | Rule |
| --- | --- | --- |
| Placeholder "Enter your email" with no label | Label "Email address", hint "We'll send your receipt here" | Visible label; hint explains why |
| First Name* / Last Name* / Middle Name* | Full name | One field unless the system truly needs parts |
| DOB | Date of birth | No abbreviations |
| Phone (required) on every field | Phone (optional) on the one optional field | Mark the minority |
| Please enter a valid phone number | Enter a phone number with area code, like 555 123 4567 | No "please valid"; give the format |

## Notifications and permissions

| Before | After | Rule |
| --- | --- | --- |
| Allow notifications? | Get notified when someone replies to you. [Turn on notifications] [Not now] | Benefit first, then the ask |
| Enable location services | Show stores near you. [Use my location] | Benefit; first person on the person's own action |
| New update available! | Version 4.2 fixes sync delays. [Restart to update] | Say what changed and the action |

## Inclusive and plain language

| Before | After | Rule |
| --- | --- | --- |
| Hey guys, welcome! | Welcome, everyone | Gender-neutral |
| Simply drag and drop your files | Drag files here, or [browse] | No "simply"; offer a non-drag alternative |
| Run a sanity check | Run a quick check | Avoid ableist idioms |
| Add to whitelist | Add to allowlist | Replace loaded terms |
| Utilize the dashboard in order to monitor KPIs | Use the dashboard to track key metrics | Plain words, fewer words |
